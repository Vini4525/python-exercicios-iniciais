# Python - Exercícios Iniciais

Este repositório reúne exercícios e mini projetos desenvolvidos durante meus estudos iniciais de Python.

Os projetos foram criados para praticar fundamentos da linguagem, como funções, condicionais, loops, listas, tratamento de erros e manipulação de arquivos.

## Projetos

### Lista de Compras
Sistema simples de lista de compras no terminal, com opções para adicionar, visualizar e remover itens.

### Diário em TXT
Programa que permite escrever e ler anotações salvas em um arquivo `.txt`.

### Sistema Escolar com CSV
Sistema de cadastro de alunos que salva os dados em um arquivo `.csv`, calcula média, define situação do aluno e permite busca por nome.

## Conteúdos praticados

- Variáveis
- Funções
- Condicionais
- Loops
- Listas
- Dicionários
- Tratamento de erros com try/except
- Leitura e escrita de arquivos
- Arquivos CSV

## Objetivo

Registrar minha evolução prática no aprendizado de Python e construir repertório para projetos futuros.
